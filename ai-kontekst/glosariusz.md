# Glosariusz

| Termin            | Znaczenie                                                              |
| ----------------- | ---------------------------------------------------------------------- |
| **ChatGPA**       | Ten projekt — Cursor do szkoły                                         |

| **ROI**           | Szacunek „ile średniej / terminu zyska godzina nauki”                  |
| **Tracker wiedzy**| Mapa temat → mastery (0–3) + spaced repetition                         |
| **Ask / Plan / Agent / Focus** | Tryby pracy jak w Cursorze                                |
| **LibrusSnapshot**| Znormalizowany zrzut ocen/terminów z syncu                             |
| **Faza 0**        | Chat + darmowe AI (zrobione)                                           |
| **PWA**           | Progressive Web App — instalowalna strona + (później) push             |
| **Badge modelu**  | UI pod odpowiedzią: `provider/model`                                   |
| **Quiet hours**   | Okno bez pushy                                                         |
